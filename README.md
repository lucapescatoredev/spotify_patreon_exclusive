# Spotify Exclusive Episodes Finder

A Chrome extension that adds filtering and search controls to Spotify podcast pages, making it easy to find Patreon-exclusive episodes.

## Features

- **Filter episodes** by category: All, Patreon Exclusive, or Free
- **Search** episodes by title
- **Visual highlight** for exclusive episodes (green left border)
- **Episode counter** showing how many episodes match the current filter

## Installation

1. Download or clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select this folder

## Usage

Navigate to any podcast page on [open.spotify.com](https://open.spotify.com). The extension automatically adds filter tabs and a search bar above the episode list.
